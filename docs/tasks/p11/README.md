# Phase 11 — Primary Baseline Freeze + Observatory Bridge

Phase 11 is intentionally short.

Baseline: `0.11.0`.

It replaces the prior Final Acceleration campaign with a bridge into the approved observability-first roadmap.

Goals:
- freeze the accepted Phase 10 single-primary-model architecture;
- add bounded presentation-independent observability projections in application/core;
- make provider-facing request composition and actual tool/GEP selection inspectable;
- record one representative primary-model baseline;
- hand a stable evidence contract to Phase 12.

Prompt order:

1. P1 — baseline identity + Observability Projection v1 — Sol High — `0.11.1`;
2. P2 — provider request and model-decision observability — Sol High — `0.11.2`;
3. P3 — primary baseline qualification — Sol Medium — `0.11.3`;
4. P4 — Phase 11 closeout — Sol Medium — `0.11.4`.

Explicitly deferred:
- speculative decoding;
- further blind GEP-selection tuning;
- helper inference;
- runtime/GPU experiments;
- daemon/Tauri implementation;
- browser/visual features.

Phase 12 follows immediately after a Green Phase 11 closeout.
