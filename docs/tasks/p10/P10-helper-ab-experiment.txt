TASK: Phase 10 / P10 — Bounded non-authoritative helper A/B experiment

MODEL / REASONING / USAGE
- Recommended configuration: `Sol High`.
- Browser required: no.

VERSIONING
- This prompt's assigned project version is `0.10.10`.

GOAL

Run exactly one bounded helper-model A/B experiment after the primary-only Phase 10 baseline is frozen.

This is research/qualification work. Do not silently promote the helper to production authority.

PREREQUISITE

Require P9 to state that the primary-only baseline is coherent and ready for the helper experiment.

EXPERIMENT SCOPE

Give the helper exactly one narrow evidence-preparation job.

Preferred candidates:
- recent tool-result/history compression;
- relevance selection/ranking for already-authorized evidence.

Choose the smallest candidate that can be measured cleanly against a same-workload primary-only control.

HELPER AUTHORITY

The helper:
- receives only bounded derived/non-secret evidence;
- cannot invoke tools;
- cannot mutate;
- cannot grant permissions;
- cannot own TaskState/StackState;
- cannot decide validation/completion;
- cannot replace canonical evidence;
- cannot silently drop required/current/recovery/safety state.

Its output is derived advisory context only.

A/B DESIGN

Run one control and one helper-assisted attempt on the same frozen representative workload/fixture under the same main-model/runtime settings.

Measure:
- task success/hidden acceptance;
- primary provider rounds;
- primary input/output tokens;
- primary provider-active time;
- helper inference time/tokens;
- total elapsed;
- retries;
- evidence retained;
- new failure modes.

No repeated batch until favorable.

FAILURE/DEGRADE

Helper unavailable/failure must degrade explicitly to the primary-only path or terminate according to authored experiment policy. No hidden behavior change.

DECISION

Create `docs/tasks/p10/P10-helper-ab-report.md`.

Classify:
- promising for Phase 12;
- no net benefit;
- harmful/unsafe.

Do not make the helper part of the accepted Phase 10 production baseline.

Do not:
- broaden helper jobs;
- allow helper tools/permissions;
- rerun until Green;
- alter P9 primary-only evidence.
