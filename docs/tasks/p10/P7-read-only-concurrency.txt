TASK: Phase 10 / P7 — Dependency-safe read-only concurrency

MODEL / REASONING / USAGE
- Recommended configuration: `Sol High`.
- Browser required: no.

VERSIONING
- This prompt's assigned project version is `0.10.7`.

GOAL

Execute proven-independent replay-safe observation calls concurrently while preserving deterministic George evidence and Phase 9 safety boundaries.

Read Phase 10 authority, P6 batch representation, ToolRegistry execution/effect metadata, cancellation/budget/recovery code, and tests.

PARALLEL ELIGIBILITY

Initial eligible class is only independent replay-safe local observations, such as:
- `read_file`;
- `list_directory`;
- `search_text`;
- `git_status`;
- `git_diff`;
when canonical execution metadata and dependency analysis prove safe independence.

INELIGIBLE

Keep sequential:
- workspace mutations;
- processes with effects;
- approval-bearing operations;
- external/remote/browser mutations;
- ambiguous/unknown effects;
- calls whose arguments/meaning depend on another call's result.

EXECUTION

A concurrent batch must:
- share bounded cancellation;
- retain one stable operation identity per call;
- enforce each tool's normal validation/policy;
- preserve original provider-call order in normalized results regardless of completion order;
- isolate failures;
- account budgets/tool execution exactly once;
- leave recovery/ambiguous-effect semantics unchanged.

Do not create a second execution authority.

METRICS

Record:
- concurrent read count;
- batch wall time;
- summed child tool runtime;
- parallel efficiency;
- provider-round count remains separately measured.

PERMANENT REGRESSIONS

Cover:
- true parallel overlap under controlled fake tools;
- deterministic result ordering;
- cancellation fanout/cleanup;
- one child failure with successful sibling evidence preserved;
- no concurrency for mutations/process/approval/ambiguous tools;
- duplicate/no-progress correctness;
- TaskState/evidence freshness unaffected.

VALIDATION

Run focused tool/execution/recovery/agent-loop tests, benchmark independent-multi-tool, fast live gate once, typecheck, runner, broad suite, and `git diff --check`.

Classify accept/revise/revert. Retain only if end-to-end benefit is measurable or it materially reduces serialization in representative batches.

Do not:
- parallelize dependent operations;
- introduce multi-agent scheduling;
- add helper inference.
