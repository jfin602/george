## P9 measurement and cleanup detail

The retained contract is opt-in. `ProviderRequest.outputPolicy.maxOutputTokens` is included only when an application explicitly requests it and the adapter advertises support. LM Studio maps it to Responses `max_output_tokens`; an unsupported adapter receives no limit and the attempt records `inherited`. Ordinary Human requests, structured inspection/implementation/correction, and validation discovery therefore preserve the accepted P8 generation behavior. Provider `response.incomplete` with reason `max_output_tokens` remains a terminal normalized error for that attempt; George never executes or commits a partial tool/control proposal.

The initial automatic trial used 8192 tokens for read-only inspection, 32768 for implementation/correction, and 16384 for validation discovery. The affected deterministic floor stayed Green, including a 48 KiB completed function argument reported as 12400 actual output tokens in the fixture. That proves George does not locally trim a completed payload; it does not prove that the limits reduce generation cost on LM Studio. Because the supported provider was unavailable and Node was below the qualification floor, output-token/provider-time benefit could not be measured. R11 therefore removes all automatic ceilings while keeping the explicit contract, adapter mapping, requested/applied/inherited metrics, actual provider usage, internal-text counts, and completed tool/control-payload counts.

The residual-round audit found no additional safe removal. Structured inspection still needs model-selected observations; implementation and correction still need semantic reasoning and a completed tool/control response; DISCOVER still needs one semantic executable/argv proposal; literal validation, revalidation, passing-validation advancement, task completion, and stack progression are already George-owned without provider confirmation. Operation prose remains bounded, ignored, and absent from the operator transcript. No new model round was removed, and no provider-round benefit is claimed. B2/C2 were not run.
