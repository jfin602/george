PART B — GEN-OP V1

Add an explicit internal structured operation mode for implementation/correction rounds.

Stable protocol instruction:
- emit only required executable tool call(s) or George handoff control;
- do not narrate routine reasoning, progress, intent, or completion;
- George owns validation/completion.

Add one provider-visible, application-owned non-executable control:

`george_control {"op":"handoff"}`

The exact internal type/name may be refined, but semantics must match the decision record.

Do NOT register it with ToolRegistry.

Valid handoff:
- requires a completed provider response;
- stops only the current model-operation stage;
- executes no tool;
- grants no permission;
- makes no TaskState/validation claim;
- returns orchestration to StructuredTaskApplicationService.

Structured implementation/correction internal rounds should require a provider tool/control choice on every logical round.

Ordinary user-facing turns remain conversational.

Fail closed on malformed/unknown controls.

Define/test deterministic behavior for:
- handoff plus executable tool in same response;
- multiple handoffs;
- free text plus handoff/tool;
- tool-free free text in internal operation mode.

Do not execute any streamed proposal before `provider.response.completed`.
