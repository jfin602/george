REQUIREMENTS

- R1: Add a separate Linux workspace-sandbox process executor using bwrap; do not retrofit autonomous approval onto the existing host run_process executor.
- R2: Detect bwrap availability and required namespace/mount support without shell execution and expose bounded capability evidence.
- R3: Keep the provider-facing logical process interface stable where practical while internal ToolExecutionMetadata/evidence clearly distinguishes sandboxed workspace process from host_process.
- R4: Build a minimal mount namespace: canonical workspace RW at its canonical path, only required system runtime roots RO, current Node/toolchain root RO when needed, isolated HOME/TMP, and only required proc/dev facilities.
- R5: Do not use --ro-bind / / or otherwise expose arbitrary user-home/sibling/temp files as the sandbox security model.
- R6: Deny network by default with an isolated network namespace; only effective user authority can enable network, and Task Prompt PERMISSIONS alone can never grant it.
- R7: If effective network policy is ask, do not silently share host networking; require explicit policy/approval/fallback semantics.
- R8: Preserve shell-false executable/argv semantics, sanitized environment, bounded stdout/stderr, timeouts, cancellation, descendant cleanup, run budgets, replay/recovery evidence, and Git/user-work preservation.
- R9: If bwrap setup is unavailable or fails, autonomous process execution fails closed or falls back to the existing host process path with its normal explicit approval and truthful non-sandboxed warning.
- R10: Add real-Linux adversarial qualification when bwrap is available: workspace read/write succeeds; sibling/outside sentinel read/write fails; symlink/traversal escape fails; secret env is absent; representative Node/npm/test/typecheck/Git-read commands work; network-deny is real; timeout/cancellation cleanup remains bounded.
- R11: Deterministic command-construction/capability tests must not be represented as real containment proof when bwrap cannot actually run.
- R12: Set package version to 0.9.8 and preserve standard-mode host process behavior.
